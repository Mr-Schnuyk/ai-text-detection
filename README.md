# Исследование методов выявления сгенерированных текстов

Курсовая работа, посвященная сравнительному анализу и практической реализации методов обнаружения текстов, созданных искусственным интеллектом (LLM).

## Описание проекта

В работе исследуются как классические подходы машинного обучения, так и современные методы на основе нейросетевых языковых моделей. Практическая часть реализована в виде Jupyter Notebooks.

### Структура репозитория

* **`Исследование методов выявления сгенерированных текстов.docx`** — полный текст курсовой работы (теоретическая и практическая части).
* **`Исследование методов выявления сгенерированных текстов.pptx`** — презентация для защиты курсовой работы.
* **`met1.ipynb`** — Реализация метода на основе логистической регрессии с использованием признаков TF-IDF.
* **`met2.ipynb`** — Реализация метода на основе n-грамм.
* **`met3.ipynb`** — Реализация метода Fast-DetectGPT.
* **`qwen.ipynb`** — Дообучение (fine-tuning) языковой модели Qwen 2.5 0.5B для задачи классификации сгенерированных текстов.
